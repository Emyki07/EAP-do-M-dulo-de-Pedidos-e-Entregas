# Módulo de Pedidos e Entregas

**Autora:** Emily Matos Vieira

## Objetivo

Este repositório tem como objetivo documentar a Estrutura Analítica do Projeto (EAP) do Módulo de Pedidos e Entregas, organizando o escopo em entregas hierárquicas para facilitar o planejamento e o acompanhamento do projeto.

## Conteúdo

- `EAP.md`: estrutura analítica do projeto organizada em três níveis.

## Organização

A EAP está dividida em requisitos, projeto, construção e entrega, com foco em produtos e resultados concretos do projeto.
